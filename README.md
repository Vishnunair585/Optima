# What is Optima?

Choosing an AI tool shouldn't involve opening twenty browser tabs, reading dozens of reviews, and experimenting with multiple products before finding the right one.

**Optima** was built to solve this problem.

Instead of searching across multiple websites, Optima provides a single platform where users can:

- Discover AI tools
- Compare competing products
- Explore curated AI stacks
- Find prompts
- Estimate AI costs
- Make informed technology decisions

Whether you're a student, developer, founder, creator, researcher, or enterprise team, Optima helps you identify the best AI solution for your specific workflow.

---

# Why Optima?

Every day, hundreds of new AI products are launched.

Questions every user faces include:

- Which AI tool is actually the best?
- Which model gives the highest quality output?
- Which AI is the most affordable?
- Which AI should I use for my specific task?
- What are the trade-offs between competing tools?
- How much will using these AI models cost every month?

Optima is designed to answer these questions through a unified experience.

# Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Optima.git
```

Go into the project

```bash
cd Optima
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build

```bash
npm run build
```

---

# Environment Variables

Create a `.env` file.

```
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=

VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=

EMAIL_SERVICE_KEY=

...
```

Never commit secrets.
